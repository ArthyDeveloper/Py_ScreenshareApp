# Scalie

A screenshare app made with Python in 1 week.  
  
This was my first try coding network features and async heavy functions, so some features like the screenshare + webcam overlay is slow and needs improvement.  
  
It works based on local network, so any computer connected to the same network as the stream host can watch it.  

For long distance hosting, a VPN like Radmin or Hamachi is needed. The faster and robust the VPN / Network between the clients, the smoother your hosting / watching will be.  
  
There is no plans to include audio to the streams since it would require more hardware power than it already uses and because this tool is just a workaround to a question i don't intend on speaking of here.

If anything breaks "permanently", you can always delete you're config file on %APPDATA%/ArthyDev/Screenshare and reset the app.
